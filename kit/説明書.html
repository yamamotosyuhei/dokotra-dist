どこでも翻訳 説明書

英語にマウスを当ててキーを押すと、その場で日本語に訳します。日本語なら英語に訳します。 VS Code・Chrome・Discord・メール・PDF など、どのアプリの上でも使えます。 訳も文字の読み取りも、すべてこの Mac の中で行います（文章をネットに送りません）。

使い方

その場で訳す（option＋control＋Y）

  1. 訳したい文にマウスを当てる
  2. option＋control＋Y を押す

  3. すぐ下に小窓が出て、訳が出ます（だいたい 0.5〜1 秒）

  4. 同じ所でもう一度押すと、前後の文までまとめて、広げて訳し直します

  5. 小窓はマウスを離すと閉じます。閉じたくない時は「ピン」
  6. 「コピー」で訳をコピー。「原文」で原文の表示と非表示を切り替えます

原文の単語だけ訳す

小窓の「原文」の中で知りたい単語を押すと、その単語の訳と辞書の意味が原文の下に出ます。もう一度押すと消えます。 単語にマウスを乗せると下線が付きます。

窓ごと訳す（option＋control＋U）

いちばん前の窓の文字をまとめて訳し、その上に重ねて表示します。もう一度押すと消えます。

小窓の色

  • 紫〜桃：英語 → 日本語
  • 青〜水色：日本語 → 英語

訳さない物

コード・URL・ファイルの場所（パス）は、訳さずにそのまま残します。 原文の数字が訳から消えていたら、⚠ で知らせます。

メニュー（画面右上の「訳」）

項目 すること
窓ごと訳す option＋control＋U と同じ
最近の訳 最近の 15 件。選ぶとコピー（終了すると消える）
翻訳言語を入れる… 翻訳の言語データの設定を開く
画面収録の許可…／アクセシビリティの許可… 許可の設定を開く
ログイン時に起動 Mac を立ち上げた時に自動で起動する（最初はオン）
再起動 許可を入れた後に押す
終了 どこでも翻訳を止める

要る物

  • Apple Silicon（M1 以降）の Mac・macOS 26.4 以上
  • 許可：画面収録（必須）・アクセシビリティ（あると Mac 標準のアプリで正確になる）
  • 翻訳の言語データ：日本語と英語（米国）（「訳」→「翻訳言語を入れる…」）
  • 単語の辞書（なくても訳は出る）：辞書アプリ → 設定 →「ウィズダム英和辞典」「ウィズダム和英辞典」

AI を使わずに入れる

  1. zip を展開したフォルダを開き、フォルダの上で右クリック →「フォルダに新規ターミナル」
  2. bash install.sh と打って return
  3. 「アクセシビリティ」の許可：システム設定 → プライバシーとセキュリティ → アクセシビリティ →「どこでも翻訳」を ON
  4. 「画面収録」の許可：英語の文にマウスを当てて option＋control＋Y → 出た画面から設定を開く →「どこでも翻訳」を ON →「終了して再度開く」（出なければ「訳」→「再起動」）
  5. もう一度 option＋control＋Y。小窓に訳が出れば完了

マウスのボタンで訳したい時

ボタンに命令を割り当てられるアプリ（BetterTouchTool など）で、次の命令を割り当てます。

  • その場で訳す：/Applications/どこでも翻訳.app/Contents/MacOS/dokotra-cli trigger read
  • 窓ごと訳す：/Applications/どこでも翻訳.app/Contents/MacOS/dokotra-cli trigger window

記録について

使った回数と、かかった時間だけを、この Mac の ~/Library/Application Support/Dokotra/usage.jsonl に残します。 訳した文章は残しません。どこにも送りません。消しても動きます（5MB を超えると古い分から入れ替わります）。

困った時

出たこと 直し方
「開発元を確認できないため開けません」 zip のフォルダで bash install.sh をもう一度
「画面収録の許可が要ります」 システム設定 → プライバシーとセキュリティ → 画面収録 で ON →「訳」→「再起動」
「翻訳の言語データがありません」 「訳」→「翻訳言語を入れる…」で日本語と英語（米国）を入れる
「マウスの所に文字が見つかりませんでした」 文字の真上にマウスを当てて押す（余白では出ない）
キーを押しても何も起きない 画面右上に「訳」があるか。無ければアプリケーションフォルダの「どこでも翻訳」を開く
単語の意味が出ない 辞書アプリ → 設定 → ウィズダム英和辞典・和英辞典にチェック
新しい版に入れ替えたら訳せない 許可がやり直しになっている。画面収録・アクセシビリティの一覧で「どこでも翻訳」を「−」で消し、「＋」で入れ直して ON

消す（アンインストール）

  1. 「訳」→「終了」
  2. アプリケーションフォルダの「どこでも翻訳」をゴミ箱へ
  3. （任意）~/Library/Application Support/Dokotra をゴミ箱へ
  4. システム設定の「画面収録」「アクセシビリティ」「ログイン項目」から「どこでも翻訳」を「−」で消す
