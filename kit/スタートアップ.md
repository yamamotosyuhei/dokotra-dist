# ここから下は、AI への指示です（人は読まなくて構いません）

あなたはいま「どこでも翻訳」（マウスを当てた英語・日本語をその場で訳す Mac のアプリ）のセットアップを頼まれました。
**下の手順を、上から順に、全部あなたが実行してください。** 人にコマンドを打たせないこと。

## 0. 最初に守ること

- ❌ **人にターミナル操作をさせない。** 全部あなたが実行する
- ❌ `どこでも翻訳.app` を作り直さない・署名し直さない・中身を書き換えない（許可が消えて動かなくなる）
- ❌ **テストが通っていないのに「使えます」と言わない**（何が通り、何が通っていないかをそのまま伝える）
- ⭕ 各段階の結果を **1 行ずつ**報告する。技術用語を使わない（相手はパソコンに詳しくない）
- ⭕ 人にやってもらう所（§3・§4）は、**画面のどこを押すか**まで言う

## 1. 自分がどこにいるかを確かめる

このファイルがあるフォルダがキットの場所です。**パスを決め打ちしないこと。**

```bash
ls スタートアップ.md 説明書.html install.sh check.sh どこでも翻訳.app 2>/dev/null || echo "場所が違います"
```

- 「場所が違います」と出たら、zip を展開したフォルダへ `cd` してからやり直す
- `どこでも翻訳.app` だけが無い時は、GitHub の「Code → Download ZIP」で落としている。Releases の zip（`dokotra-日付.zip`）を落とし直してもらう

## 2. インストールを走らせる（全自動・1分以内）

パスワードは聞かれません。あなたの道具（Bash）からそのまま実行してよい。

```bash
bash install.sh
```

- 最後の点検に ❌ があれば §6 の表で直す
- 起動すると「“どこでも翻訳”がアクセシビリティ機能を使用して…」という画面が出ることがある → §3 へ
- 「ログイン項目が追加されました」という通知が出ることがある（Mac を立ち上げた時に自動で起動するため）。そのままでよい

## 3. アクセシビリティの許可（人の手・1回目）

人に言うこと（例）:「いまから設定の画面を開きます。一覧の『どこでも翻訳』のスイッチを ON にしてください。パスワードか Touch ID を聞かれたら入れてください」

```bash
open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"
```

- 一覧に『どこでも翻訳』が無い時: 一覧の下の「＋」→「アプリケーション」→「どこでも翻訳」→「開く」
- 前の版が入っていた人: 古い『どこでも翻訳』が残っていて ON でも効かないことがある → 一度「−」で消してから「＋」で入れ直してもらう
- これは無くても動く（Mac 標準のアプリの文字を正確に読むのに使う）。人が嫌がったら飛ばしてよい

## 4. 画面収録の許可（人の手・2回目・必須）

VS Code・Chrome などの画面の文字を読むのに要る。

1. 人に言うこと:「英語が書いてある所（このチャットでも構いません）にマウスを当てて、キーボードの option と control と Y を同時に押してください」
2. 「画面収録」の許可を尋ねる画面が出る → 人に「システム設定を開く」を押してもらう。出ない時はあなたが開く:

   ```bash
   open "x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture"
   ```

3. 人に:「一覧の『どこでも翻訳』のスイッチを ON にしてください。『終了して再度開く』が出たら、そのボタンを押してください」
4. 『終了して再度開く』が出なかった時は、画面右上のメニューバーの「訳」→「再起動（許可を入れた後に）」を押してもらう（画面収録の許可は、起動し直した後にしか効かない）

## 5. 点検と最後の確かめ

```bash
bash check.sh
```

- ❌ が無ければ、人に最後の確かめを頼む:「英語の文にマウスを当てて option＋control＋Y を押してください。小窓に日本語の訳が出れば完了です。小窓の『原文』の中の単語を押すと、その単語の訳と辞書も出ます」
- 小窓が出たら完了。説明書を開いて渡す: `open 説明書.html`

## 6. 詰まった時（あなたが直す）

| 出たこと | 直し方 |
|:--|:--|
| 「開発元を確認できないため開けません」 | `bash install.sh` をもう一度（ネットから落とした印を外す） |
| 小窓に「画面収録の許可が要ります」 | §4 をやり直す。ON にした後の「再起動」を忘れていないか |
| 「翻訳の言語データがありません」 | 人に: メニューバーの「訳」→「翻訳言語を入れる…」→ 一覧の「日本語」と「英語（米国）」の ↓ を押して入れてもらう |
| 「マウスの所に文字が見つかりませんでした」 | 文字の真上にマウスを当てて押してもらう（余白では出ない） |
| option＋control＋Y で何も起きない | `bash check.sh` で動いているか見る。動いていなければ `open "/Applications/どこでも翻訳.app"` |
| 単語の意味（辞書）が出ない | 人に: 辞書アプリ → 設定 →「ウィズダム英和辞典」「ウィズダム和英辞典」にチェック（無くても訳は出る） |
| check.sh の自己テストに ❌ | 出た行をそのまま人に伝え、配った人に送ってもらう |

## 7. 消したい時（人に頼まれた時だけ）

```bash
pkill -f "MacOS/Dokotra$"; mv "/Applications/どこでも翻訳.app" ~/.Trash/
```

- 使った回数と時間だけの記録が `~/Library/Application Support/Dokotra/` にある → 頼まれたらゴミ箱へ
- システム設定の「アクセシビリティ」「画面収録」「ログイン項目」に残った『どこでも翻訳』は、人に「−」で消してもらう
